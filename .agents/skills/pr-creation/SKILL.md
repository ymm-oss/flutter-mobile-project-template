# プルリクエスト作成

プルリクエスト作成を依頼されたら、次の順で進める。タイトルと本文をユーザーが確認する前に、push や作成はしない。

## 1. 作成に必要な情報を集める

リポジトリのルートで次を実行する。

```shell
./scripts/diff.sh
```

このスクリプトは [scripts/diff.sh](../../../scripts/diff.sh) にあり、次を表示する。

- 作業ブランチ
- Issue 番号（ブランチ名に `GH-数字` が含まれる場合）
- 派生元ブランチ
- 変更されたファイル一覧
- 変更の差分

## 2. タイトルと本文を作る

手順 1 の情報と [.github/PULL_REQUEST_TEMPLATE.md](../../../.github/PULL_REQUEST_TEMPLATE.md) から、タイトルと本文を作る。

- Issue 番号がある場合は、概要にその Issue へのリンクを書く。
- 画像や動画、テンプレートにない見出しは足さない。
- 作ったタイトルと本文を提示し、ユーザーの確認を待つ。

## 3. プルリクエストを作成する

ユーザーがタイトルと本文を確認したあとに作成する。

- リモートに作業ブランチが無い場合は、先に `git push -u origin HEAD` する。
- `owner` と `repo` は指定しない。現在のリポジトリ（`git` の remote、または `gh` が解決するリポジトリ）を使う。
- `gh pr create` が使える場合は、派生元ブランチを base にして作成する。
- GitHub MCP が有効な場合は、同じタイトルと本文で作成してもよい。

作成後は、プルリクエストの URL をユーザーに示す。
